# SIGNALIUM S18 — QDE INFERENCE GATEWAY, MARKET DATA INFRASTRUCTURE AND RUNTIME INTELLIGENCE LAYER

Repository:
signalium

Related Repository:
signalium-trainer

Objective:

Create the runtime infrastructure that allows the Signalium Quant Decision Engine (QDE) to continuously observe markets, generate decisions, manage positions, and communicate with EAs in real time.

The QDE must operate as a professional trader rather than as a signal generator.
