# SIGNALIUM S17 — EA PROVISIONING, API AUTHENTICATION AND AUTONOMOUS TRADING CONTROL PLANE

Repository: signalium

Objective:
Implement the infrastructure that allows Signalium users to operate in either Manual Trading Mode or Fully Autonomous Trading Mode using a uniquely generated MT5 Expert Advisor that communicates securely with the Signalium Quant Decision Engine (QDE).

The Signalium platform remains the front office.
The Signalium Trainer remains the brain.
The EA becomes the execution arm.

────────────────────────

1. USER TRADING MODES
   ────────────────────────

Implement two mutually exclusive trading modes:

### Manual Mode

The user receives:

* market context
* directional bias
* confidence score
* reasoning
* entry zones
* invalidation levels
* projected hold duration
* probability estimates

The user places and manages trades manually.

Signalium does not send execution instructions to the EA.

---

### Fully Autonomous Mode

The user authorizes Signalium to manage trading.

The QDE:

* monitors markets continuously
* identifies opportunities
* sends trade instructions
* manages open trades
* closes trades
* scales positions
* exits early if conditions deteriorate
* protects capital during regime changes
* avoids unnecessary drawdown

The EA becomes execution-only.

The EA never makes trading decisions.

The QDE remains the sole decision maker.

────────────────────────
5. UNIQUE EA GENERATION
────────────────────────

Each user receives a unique EA package.

Naming convention:

Signalium_Brian_MT5.ex5
Signalium_John_MT5.ex5

Generated dynamically using:

platform prefix
user name
build version
subscription tier

The EA contains:

* API endpoint
* API key placeholder
* polling interval
* build version
* supported symbols

No trading logic exists inside the EA.

The EA only:

* receives instructions
* executes instructions
* reports positions
* reports account state

────────────────────────
6. EA TO SERVER COMMUNICATION
────────────────────────

Polling interval:

15 seconds default.

Configurable by admin.

EA sends:

* account balance
* equity
* free margin
* margin level
* open positions
* floating profit/loss
* current stop loss
* current take profit
* current spread
* broker symbol
* execution status

The server returns:

NO_ACTION

OPEN_BUY

OPEN_SELL

MODIFY_POSITION

PARTIAL_CLOSE

MOVE_SL

MOVE_TP

FULL_CLOSE

SCALE_IN

REDUCE_EXPOSURE

7. POSITION TELEMETRY LOOP
────────────────────────

The EA must continuously report:

* unrealized PnL
* drawdown
* duration
* current spread
* swap
* commissions
* slippage
* fill quality

This information is forwarded to the trainer.

The QDE uses this information to:

* reassess confidence
* update probability estimates
* detect reversals
* identify deteriorating setups
* optimize exits

This creates continuous trade awareness.

The model remains alive throughout the trade.
