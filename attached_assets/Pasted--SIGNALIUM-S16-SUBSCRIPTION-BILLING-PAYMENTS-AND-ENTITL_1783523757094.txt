## OBJECTIVE

Implement the complete commercial infrastructure for Signalium.

Signalium is a premium institutional trading platform.

There is no free tier.

No feature should be accessible without an active subscription.

All trading functionality, market analysis, API access, EA generation and autonomous trading capabilities must be protected behind subscription entitlements.

# GRACE PERIODS

Implement:

7 day grace period after failed renewal.

During grace period:

* manual mode remains available
* autonomous mode disabled
* EA polling denied

After grace period:

all entitlements revoked.

# EA ACCESS CONTROL

EAs cannot function without active entitlement.

EA polling endpoints must verify:

* API key validity
* subscription status
* entitlement status
* active package
* allowed symbol count
* autonomous permission

If validation fails:

return machine readable denial response.

Example:

SUBSCRIPTION_EXPIRED
AUTONOMOUS_DISABLED
SYMBOL_LIMIT_REACHED
INVALID_API_KEY
